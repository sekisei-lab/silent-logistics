# 無言オペレーション物流プラットフォーム（MVPプロトタイプ）

外国籍ドライバーが日本語を話さなくても、配車予約・場所指示・作業依頼・進捗確認・到着確認を会話なしで完結できる物流プラットフォームの MVP デモです。依存パッケージなし（Node.js 20+ のみ）。

| 画面 | URL | 内容 |
| --- | --- | --- |
| ドライバーアプリ | `/driver/` | 母国語（ja/zh）＋絵記号で、受諾→出発→受付→呼び出し→荷役→完了、トラブル報告、音声読み上げ |
| 荷主・拠点ポータル | `/portal/` | 輸送依頼、バース呼び出し、作業依頼、現場ガイド（拠点マスタ）登録、進捗確認、トラブルへの定型文返信 |
| 配車・運行管理デスク | `/desk/` | 配車（免許・在留期限・拘束時間のチェック付き）、地図で車両監視、アラート |

## 起動

```bash
npm start        # http://localhost:3000
npm test         # 業務フローのスモークテスト
```

環境変数: `PORT`（既定3000）、`DATA_DIR`（既定 `./data`）、`SIMULATE=0`（GPSが届かない車両のデモ自動移動を止める）。

## 実装済み範囲（要件定義 MVP）

D-01〜D-09 のうち D-01 を除く主要機能、S-01〜S-07、O-01〜O-04・O-06、A-01〜A-03 の簡易版。

## 未実装・割り切り

- 認証なし（画面上でユーザーを選ぶデモ用ログイン）。本番では A-01 のとおりロール別認証が必要
- データは JSON ファイル保存（Render 無料枠では再起動で初期化）。本番では RDB に置き換え
- 対応言語は日本語と中国語（簡体字）のみ。辞書は `public/shared.js` に言語を追加するだけで拡張可能（en/vi/id の訳文は保持）
- 翻訳は初稿。運用前にネイティブチェックが必要（A-02）
- 点呼・デジタコ・WMS 連携、自動配車、写真保存、オフラインキュー、通訳チャットは未実装
- 位置情報はブラウザのGPS。許可がない車両はデモ用に自動で移動

デモデータはすべて架空です。
